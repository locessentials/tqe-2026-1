# PAT-TQE-2026-1

This repository is for the dashboard that inter-annotator agreement for the TQE-2026-1 evaluation project series. This effort has two main objectives: first, to train a team of professional evaluators to produce consistent, deployable annotations of translation quality; and second, to use the annotations to draw conclusions about corpus-informed, document-level automatic translation quality produced from our Pragmatic Auto-Translator (PAT).

The reports shared here have been generated from Label Studio annotations of translation quality errors according to MQM. The reports were generated using the notebooks made available here: https://github.com/locessentials/translation-quality-evaluation/

You can learn about our findings and the broader initial context for this research in our forthcoming paper, "Can an Old Dog Be Taught New Tricks? Taking LLMs Beyond Sentence Level Automatic Translation", which will be published in the proceedings of HCI International 2026.
